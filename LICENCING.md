# 🚀 FIGO - yaml based dashboard generator

[Stručný a úderný popis jedním větou, např. "Moderní a rychlý generátor boilerplate kódu pro REST API z konfigurace YAML."]

Tento nástroj vznikl jako osobní projekt s cílem zjednodušit a urychlit každodenní vývoj. Automatizuje rutinní psaní kódu, minimalizuje chyby a šetří váš čas.
